# Rich AI (RAI)
> **Pronunciation:** /raɪ/ - rhymes with **"sky"** or **"rye"** (or "paradise" in Polish :) )

### The Agentic OS Daemon & Secure Linux Gateway - Your Private Assistant for the Desktop!

**RAI** is a powerful, deeply integrated AI system daemon and agent environment designed specifically for Linux power users, developers, and researchers. It bridges the gap between sophisticated LLMs and your local system environment through a robust client-server architecture, modular desktop adapters, and a secure local execution sandbox.

By utilizing the **Google Antigravity SDK**, RAI delegates core model orchestration and session memory management to a secure, professional agent runtime. This allows RAI to focus on what it does best: providing deep, secure desktop integrations and a rich multi-client ecosystem.

---

## Key Features

* **Antigravity SDK Core:** Powered by a native `AgentRuntime` for reliable session management, step routing, and cloud-or-local AI interactions.
* **Linux-First & Modular Desktop Adapters:** Abstracted support for desktop tasks (e.g. notifications, screenshotting, focus tracking) with specialized modules for **GNOME Shell** (via D-Bus/`pydbus`) and the modern **COSMIC Desktop** (via Wayland-based Rust IPC).
* **The Security Layer (Sandboxed Execution):** Runs arbitrary terminal or shell commands generated by agents in a secure local sandbox (via `bubblewrap` or `guix shell --container`), protecting the host system from destructive actions.
* **Multi-Client Ecosystem:** Access your agent daemon (`rai serve`) seamlessly from the interactive terminal CLI, native **Emacs** packages, or a modern web dashboard built with **GNU Guile Hoot (WASM)**.

## Architecture

```
┌────────────────────────────────────────────────────────────────────────┐
│                          CLIENT APPLICATION LAYER                      │
│      [ Emacs Client ]    [ GNU Guile Dashboard (WASM) ]    [ CLI ]     │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ HTTP / WebSockets (JSON API)
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        RAI SYSTEM DAEMON (`rai serve`)                 │
│                                                                        │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │               Antigravity SDK AgentRuntime                     │   │
│   │    - Session management, routing, & history delegated to SDK   │   │
│   └───────────────────────────────┬────────────────────────────────┘   │
│                                   │ Injects secure context & tools
│                                   ▼
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │                  RAI Secure Context & Tool Layer               │   │
│   │    - Custom system tools registered via MCP or SDK decorators │   │
│   └───────────────┬───────────────────────────────┬────────────────┘   │
└───────────────────┼───────────────────────────────┼────────────────────┘
                    │                               │
                    ▼ DBus / IPC                    ▼ Bubblewrap / Guix Container
┌──────────────────────────────────────┐ ┌───────────────────────────────┐
│        DESKTOP ADAPTER LAYER         │ │      SECURE SHELL RUNTIME     │
│ [ GNOME (pydbus) ] [ COSMIC (Rust) ] │ │ (Isolated Command Execution)  │
└──────────────────────────────────────┘ └───────────────────────────────┘
```

* **Server (`rai serve`):** A FastAPI-based core that communicates with clients via REST/WebSockets and runs the Antigravity engine.
* **Desktop Adapters (`src/rai/tools/desktop/`):** Unified system adapters automatically loaded by detecting `XDG_CURRENT_DESKTOP` at startup.
* **Security sandbox (`src/rai/tools/security/`):** Safe environment wrapper that uses bubblewrap (`bwrap`) to run generated shell tools securely.

## Quick Start

### 1. Installation
Clone the repository and install dependencies with `uv`:

```bash
git clone https://gitlab.com/tk-lab1/ai/rai.git
cd rai
uv pip install -e .[test,dev,lint]
```

*For GNOME D-Bus tools integration:* `uv pip install -e .[gnome-tools]`

### 2. Configuration
Create your configurations in `~/.config/rai/agents.yaml` to define your customized agents, and standard sessions will be persisted locally in `~/.config/rai/sessions/`.

### 3. Usage
* **Interactive CLI:** `rai`
* **One-shot Inference:** `rai -p "List all active pull requests in Gitlab"`
* **Run Daemon Server:** `rai serve`
* **Connect Client to Remote Daemon:** `rai --connect`
